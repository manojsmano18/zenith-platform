You can run this project locally in two ways. Since Docker Desktop is already installed on your machine and Java 21 / Maven are not configured in your Windows host PATH, Option 1 (Docker Compose) is the recommended method.

Option 1: Full-Stack with Docker Compose (Recommended)
This runs the entire stack (PostgreSQL, Spring Boot 3 Backend, and React Frontend) in isolated containers with zero setup.

Step 1: Start Docker Desktop
Open the Start Menu, search for Docker Desktop, and launch it.
Wait a moment until the Docker whale icon in the taskbar shows that the engine is running.
Step 2: Build & Start Containers
Open your PowerShell terminal in the project root (D:\zenith-platform) and run:

powershell
docker compose up --build
(To run in the background detached, add -d: docker compose up --build -d)

Step 3: Access the Application
Service	Local URL	Description
Storefront & UI	http://localhost:3000	Full React application
Admin Portal	http://localhost:3000/admin	Merchant dashboard & telemetry
Spring Boot REST API	http://localhost:8085/api/products	Products catalog endpoint
Actuator Health	http://localhost:8085/actuator/health	Container health probe
To Stop the Project:
powershell
docker compose down
Option 2: Quick Frontend-Only Preview (Fast UI Iteration)
If you only want to quickly preview and test UI/React changes with Vite hot reloading:

powershell
cd D:\zenith-platform\frontend
npm.cmd run dev
NOTE

On Windows PowerShell, use npm.cmd run dev to bypass the PowerShell script execution policy. Your frontend will immediately be available at http://localhost:3000.
